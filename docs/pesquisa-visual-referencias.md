# 🔬 Pesquisa Visual — Refatoração Frontend FluvOS

## 🎯 Objetivo da Pesquisa

O app **FluvOS** está com visual "morno/frio/pacato". A missão é encontrar referências visuais de apps minimalistas mas **vibrantes, energéticos e bold** para guiar a refatoração do frontend.

**Problema identificado:** Interface sem personalidade, sem energia, sem vida
**Meta:** Transformar em algo minimal mas **com atitude** — bold, vibrante, moderno

---

## 📊 Tendências de Design Relevantes (2024-2026)

### 1. Dark Theme com Accent Colors Vibrantes
- Fundo escuro + cores de destaque neon/vibrantes
- Cria contraste forte que dá vida aos dados
- **Ideal para dashboards de performance** — dados "saltam" do fundo
- Exemplos: crypto dashboards, fintech apps

### 2. Glassmorphism / Liquid Glass
- Efeitos de vidro fosco com transparência e blur
- Apple adotou oficialmente com "Liquid Glass" no iOS 26
- Cria profundidade e sofisticação sem poluir
- Funciona bem em cards, modais, sidebars
- **Figma UI Kit gratuito:** [Glassmorphism Dashboard UI Kit](https://www.figma.com/community/file/1514405085901665002/glassmorphism-dashboard-ui-kit)
- **Frosted Micro UI Kit:** [Minimal Glass Components](https://www.figma.com/community/file/1563199825667468406/frosted-micro-ui-kit-minimal-glass-components)

### 3. Gradientes Saturados + Tipografia Bold
- Gradientes ousados (não pastéis) em backgrounds, cards e CTAs
- Tipografia grande e bold para hierarquia visual forte
- Combina com: dark mode, minimal layout, whitespace generoso

### 4. Linear Design (Tendência SaaS)
- Popularizado pelo app [Linear](https://linear.app)
- Layout sequencial e direto, sem distrações
- Dark mode + bold typography + gradients complexos
- **Prós:** Reduz carga cognitiva, acelera tarefas, alta performance
- **Contras:** Pode ficar genérico se não personalizar (oversaturation)
- **Artigo de referência:** [Linear Design - LogRocket](https://blog.logrocket.com/ux-design/linear-design/)

### 5. Micro-interações & Animações Sutis
- Hover states em botões e cards
- Tooltips dinâmicos nos gráficos
- Transições suaves entre estados
- Loading animations contextuais
- **Artigo:** [Stop Building Boring UI: 5 Micro-Interactions](https://medium.com/front-end-world/stop-building-boring-ui-5-micro-interactions-that-will-instantly-level-up-your-app-b5979d525ca4)

## 💡 Recomendações para o FluvOS

### O que mudar para sair do "morno":

#### 🎨 Paleta de Cores
- [ ] **Adotar dark mode** como tema principal (ou opção)
- [ ] **Accent colors vibrantes** — verde, purple, orange ou cyan como cor principal de destaque
- [ ] **Gradientes sutis** em cards de KPIs e seções de destaque
- [ ] **Contraste forte** — fundo escuro faz métricas "saltarem"

#### 🔤 Tipografia
- [ ] **Font bold/semibold** para títulos e números grandes
- [ ] **Hierarquia clara** — 3 níveis máximo (headline, body, caption)
- [ ] Considerar: **Inter, Poppins, Plus Jakarta Sans, Satoshi**
- [ ] Números de métricas em **tamanho grande e bold**

#### 📦 Cards & Layout
- [ ] **Cards com bordas arredondadas** (8-16px border-radius)
- [ ] **Sombras sutis** para profundidade
- [ ] **Glassmorphism** em elementos de destaque (sidebar, modals, cards premium)
- [ ] **Espaçamento generoso** — whitespace é seu amigo
- [ ] **Modular/card-based** layout para dados

#### 📊 Data Visualization
- [ ] **Gráficos com gradientes** em vez de cores sólidas
- [ ] **Area charts** com transparência
- [ ] **Color-coding funcional** — verde=bom, vermelho=atenção, amarelo=alerta
- [ ] **Tooltips on hover** com dados detalhados

#### ✨ Micro-interações (O que transforma de "morto" em "vivo")
- [ ] **Hover effects** em cards e botões (scale, shadow, glow)
- [ ] **Animações de entrada** para dados (fade-in, slide-up)
- [ ] **Loading skeletons** em vez de spinners
- [ ] **Transições suaves** entre páginas/views (200-300ms)
- [ ] **Progress bars animados** para métricas
- [ ] **Number counting animations** para KPIs grandes

#### 🏗️ Específico para Construction/Builder
- [ ] **Progress bars visuais** para andamento de obras
- [ ] **Status badges coloridos** (em andamento, atrasado, concluído)
- [ ] **Timeline/Gantt** simplificado para projetos
- [ ] **Cards de projeto** com thumbnail/preview
- [ ] **Dashboard overview** com métricas-chave em destaque
